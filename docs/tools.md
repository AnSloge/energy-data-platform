Energy Data Platform – Tool Placement
- Source
  - Energy / weather APIs
  - CSV / Parquet files
- Ingestion
  - Apache Airflow – schedule and orchestrate API/file ingestion
  - Python – call APIs and write raw data
- Storage
  - Local filesystem / MinIO – raw data lake
  - Bronze – raw data
  - Silver – cleaned, standardized data
  - Gold – analytics / ML-ready data
- Transformation
  - Databricks Free Edition – main transformation environment
  - PySpark – large-scale transformations
  - Delta Lake – Bronze/Silver/Gold tables
  - SQL – querying and transformations
- Machine Learning
  - scikit-learn – baseline and forecasting models
  - MLflow – track experiments, metrics and model versions
- Serving
  - DuckDB – fast analytical queries on local/Gold data
  - Streamlit / Power BI Desktop – dashboard and visualization
- Quality & Testing
  - pytest – unit, integration and data-quality tests
- CI/CD & Version Control
  - Git / GitHub – source control
  - GitHub Actions – automated tests and CI
- Monitoring / Logging
  - Python logging – pipeline logs
  - Airflow UI/logs – job status and failures
